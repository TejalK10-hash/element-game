# Element Navigator

A game where you match chemical elements to parts of spacecraft. I built it because I kept wondering what rockets are actually made of.

## How to play

Pick a spacecraft level, then drag element badges onto the right parts. If you get it right, a popup tells you why that material matters. There are four levels: rocket, shuttle, fighter jet, and space probe.

## What I used

HTML, CSS, and JavaScript. No frameworks.

## What was tricky

The SVG coordinates for the hotspots took forever to get right. I had to adjust them pixel by pixel until the dots lined up with the images.
