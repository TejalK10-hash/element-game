# Element Navigator
An interactive browser game where you drag elements onto spacecraft parts (rocket, shuttle, fighter jet, deep-space probe) and learn why each material matters. Part puzzle, part science lesson.

## How to Play
1. Pick a craft - Rocket, Space Shuttle, Fighter Jet, or Space Probe.
2. Match the elements - Drag a badge to the correct part (or tap-to-select on mobile).
3. Learn the science - Every correct match unlocks a fact card. Get it wrong, and the game nudges you toward the answer.
4. Build your streak - 3+ correct matches in a row earns bonus points.
5. Collect stars - Zero mistakes = 3 stars. Replay to improve.
6. Unlock the glossary - Finish all levels to get a full reference guide.

## Features
- 4 levels with 5 unique elements each (20 total matches)
- Drag & drop + tap controls - works on desktop and mobile
- Educational fact cards - plain-English explanations for every material
- Surprise facts - 20% chance of bonus trivia on any correct match
- Scoring & streak system - escalating bonuses for consecutive correct answers
- Star ratings - 3/2/1 stars based on mistakes per level
- Zero dependencies - HTML, CSS, JS only

## Why I Built This
Every time I read about a rocket landing itself or a probe surviving 40 years in deep space, I ask: what is this thing actually made of? The answer is always elements - specific, fascinating, extreme elements. This game is my way of making that wonder clickable.
