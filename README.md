# Element Navigator
A game where you match chemical elements to parts of spacecraft. I built it because I kept wondering what rockets are actually made of.

## How to Play
Pick a spacecraft level, then drag element badges onto the right parts. If you get it right, a popup tells you why that material matters. 
There are four levels: Rocket, Space Shuttle, Fighter Jet, and Space Probe.

## Controls
- Drag & drop - pull a line from an element badge to the matching hotspot on the spacecraft
- Tap to select - click a badge, then click a hotspot if dragging feels clumsy
- Streak bonus - get 2+ correct in a row for extra points

## Features
- 4 spacecraft levels with 5 elements each (20 total matches)
- Drag-and-drop or click-to-match gameplay
- Score system with streak multipliers
- Star ratings per level based on mistakes (0 mistakes = 3 stars)
- Fact popups explaining why each material matters
- Surprise facts that occasionally pop up (20% chance on correct match)
- Level-complete screen with star rating and next-level button
- Win screen with full glossary of all 20 materials
- Reset button to start fresh anytime

## What I Used
- HTML
- CSS
- JavaScript

## What Was Tricky
The SVG coordinates for the hotspots took forever to get right. I had to adjust them pixel by pixel until the dots lined up with the images.
